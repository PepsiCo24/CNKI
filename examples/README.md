# 示例数据说明

本目录只包含**明确标注的模拟/示例数据**，用于验证系统完整流程，不是知网实时数据，也不是真实发表的论文。

## `sample_metadata.ris`

- 5 条模拟题录，期刊名为“岩土力学”（3 条）与“岩石力学与工程学报”（1 条），另有 1 条 2019 年记录。
- 用于验收：
  - 3 条符合“岩土力学 + 2023-01-01 ~ 2025-12-31”；
  - 1 条因期刊不匹配被跳过；
  - 1 条因年份超出范围被跳过。
- 标题均带“（示例文献）”，作者为“张示例/王示例”等虚构姓名。

## `sample_papers/2023_岩土边坡稳定性预测_张示例.pdf`

- 程序生成的虚构论文，页脚与正文均标注“示例文献 · 非知网实时数据 · 仅用于系统测试”。
- 2 页，包含摘要、关键词、引言、研究方法、实验、结果、讨论、结论、参考文献，以及虚构的 MAE/R² 数值。
- 用于验证：PDF 解析、页映射、章节识别、全文 AI 分析（Mock）与审核流程。

导入到系统后，请勿将其视为真实科研结论。真实科研使用前，请配置真实大模型并导入你有权使用的真实文献。

## 生成方式

- PDF 由 PyMuPDF 使用 macOS 宋体嵌入生成；
- 所有数值与结论均为演示虚构；
- RIS 可直接被系统“导入官方题录”解析。
